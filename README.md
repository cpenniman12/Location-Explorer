# Random World Location Explorer

A simple web application that allows users to discover random locations around the world along with their local time and weather information.

## Features

- Click a button to discover a random location from a database of 40 major cities
- View the location's local time (approximated based on longitude)
- Check simulated weather conditions
- See coordinates in an easy-to-read format
- Explore the location on an interactive map

## Technologies Used

- HTML5
- CSS3
- JavaScript (vanilla)
- OpenStreetMap for map integration

## How to Use

1. Visit the website
2. Click the "Explore New Location" button
3. Discover information about a randomly selected location
4. Click the button again to explore a new location

## Notes

This application simulates weather data and approximates local time based on longitude for demonstration purposes. In a production environment, these would be fetched from real APIs.
